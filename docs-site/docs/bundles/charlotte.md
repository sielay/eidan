# Charlotte — lifestyle

**Charlotte** is an AuDHD-first companion for the rhythm of your week — one trusted companion, not a
dashboard. It's built around 30-second stolen-moment logging, your body-state as context on every
turn, and proactive nudges instead of charts you have to remember to open.

:::note In build
Charlotte is the newest bundle and is still landing — the capabilities below are the roadmap, not
shipped yet. Follow along on [GitHub](https://github.com/sielay/eidan) and the
[eidan.dev roadmap](https://www.eidan.dev/#bundles).
:::

## On the roadmap

- **Fitness** — a canonical sleep / activity / body store, Strava-first ingest
- **Nutrition + meals** — meal planning and grocery-list automation
- **Wellbeing** — mood, habits, fasting, and an ideas shelf that resurfaces
- **Proactive AuDHD nudges** — transition warnings, rest enforcement, body-doubling, a shutdown ritual
- **Calendar-aware morning brief** (via the free core)

## The design idea

Where other tools give you more dashboards to check, Charlotte is built to *reach out* — because the
hardest part isn't the data, it's remembering to look. It leans on the same core primitives
([agents & triggers](/concepts), the memory graph, notifications) as everything else in eidan.
